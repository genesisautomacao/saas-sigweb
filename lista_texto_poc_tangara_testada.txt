1. Suporte aos principais navegadores (IE, Edge, Firefox, Chrome). 😀👍🏻

2. Não necessitar de plug-ins/applets/ActiveX.
   [TESTADO ✅ por arquitetura] Todo o mapa é JavaScript puro (OpenLayers) e HTML;
   PDFs são gerados no servidor (DomPDF). Zero applet/ActiveX/Flash no código.
   COMO TESTAR: abrir o sistema num navegador limpo, sem instalar nada — funciona.

3. Interoperabilidade OGC (mínimo WMS e WFS).
   [PARCIAL ⚠️] WFS TESTADO ✅: GetCapabilities respondeu XML padrão OGC (866
   bytes) e GetFeature da camada lotes devolveu FeatureCollection com 2.000
   feições. WMS: como CONSUMIDOR funciona (camadas WMS externas persistidas por
   categoria, item 22 intranet); como SERVIDOR WMS (GetMap) está PENDENTE (T3.1
   do backlog). COMO TESTAR WFS: no QGIS, adicionar conexão WFS com a URL
   /api/ogc/prefeitura-de-santa-cecilia?service=WFS&request=GetCapabilities
   e carregar a camada "lotes".

   ⚠️**Dúvida/Erro: erro em SERVIDOR WMS: (https://webgis.liderengenharia.eng.br/api/ogc/prefeitura-de-santa-cecilia?service=WFS&request=GetCapabilities) com print em anexo
   → DIAGNÓSTICO FECHADO (2026-08-06, com os prints do engenheiro):
     a conexão foi criada no provedor ERRADO do QGIS — "WMS/WMTS" em vez de
     WFS. O QGIS então enviou service=WMS, que o servidor (só WFS hoje) recusa
     com o JSON de erro de 71 bytes ("71 de 71 bytes baixados" no print) →
     "Bad Request". O navegador abrindo o XML prova que o WFS está NO AR.
     ➤ CAMINHO GARANTIDO HOJE no QGIS (sem depender do provedor WFS nativo):
       Camada → Adicionar Camada → Adicionar Camada Vetorial →
       Tipo de fonte: "Protocolo: HTTP(S)" → Tipo: GeoJSON → URI:
       https://webgis.liderengenharia.eng.br/api/ogc/prefeitura-de-santa-cecilia?service=WFS&request=GetFeature&typeName=lotes
       (trocar typeName por quadras / logradouros / bairros para as demais).
     ➤ LIMITAÇÃO CONHECIDA: o provedor "WFS/OGC API" NATIVO do QGIS exige um
       WFS mais completo (DescribeFeatureType + capabilities com endpoints +
       saída GML/JSON anunciada) — nosso WFS mínimo serve GeoJSON. Esse
       upgrade "WFS nível QGIS" foi incorporado ao escopo do T3.1 (junto com
       o WMS GetMap).
